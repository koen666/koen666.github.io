# 科研与竞赛

# 1. Channel-Aware Gradient Awakening for Unpaired Visible-Infrared Person Re-identification

TPAMI 2026 under review
Bin Yang*, Ke He*, Wenke Huang, Haoyu Yao, Bo Du, Mang Ye

  • 针对非配对可见光-红外行人重识别中前向优化易饱和、孤立样本强制匹配导致错误监督传播的问题开展研究。
  • 提出 CAGA 框架，通过通道感知双向梯度提取、多视图最优传输筛选和双向记忆协同补偿，提升跨模态匹配鲁棒性与伪配对质量。

# 2. See Before You Code: Learning Visual Priors for Spatially-Aware Animation Generation

under review
Ke He*, Yuejia Li*, Junhen Li, Jingkang Xia, Mang Ye

  • 针对多智能体动画生成中缺乏显式空间感知、易出现布局重叠、越界与时序不连贯等问题开展研究。
  • 提出视觉先验驱动的 OmniManim 框架，将布局规划与代码生成解耦，并结合扩散式布局预测与渲染反馈迭代优化动画质量。

# 3. Beyond the Token Bottleneck: Latent Communication Has a Receiver-Consumption Bottleneck

NeurIPS 2026 under review
Yuejia Li*, Ke He*, JunHeng Li, Mulei Zhang

  • 针对多智能体 LLM 潜变量通信中重发送端表达、轻接收端消费的问题，提出 receiver-consumption bottleneck 视角。
  • 系统分析 hidden states、latent prefix、KV cache 等接口的不同消费语义，主张以接收端可读性、扰动鲁棒性和跨模型可迁移性验证潜变量通信协议。

# 4. MARVT: Meta-Learned Aerial-Ground Residual View Translation for Cross-Domain Person Re-Identification

NeurIPS 2026 under review
Yike Xiang, Yuejia Li, Yubing Hu, Ke He, Shuoyi Chen, Mang Ye

  • 面向跨域空地行人重识别，研究现有方法依赖源域空地视角对应关系、在未见目标域性能下降的问题。
  • 提出 MARVT 框架，通过元视角学习与特征空间残差视角翻译，学习身份保持的空地视角迁移表示，提升跨域泛化能力。

# 5. Seeding: Small Updates, Persistent Poisoning in GraphRAG

NeurIPS 2026 under review
Zubin Chen*, Ke He*, Ke Qiu, Zhiyue Su, Duanning Chen, Yuyang Zhang, Run Wang

  • 针对动态增量更新的 GraphRAG 系统，揭示小规模节点级投毒可通过社区摘要层长期存续并持续影响下游回答。
  • 构建 DPG 动态投毒基准并提出 Seeding 框架，在多轮良性更新后仍保持较高攻击成功率，验证其长时程安全风险。

# 6. AI-assisted Learning Silently Degrades Metacognition: Detection, Quantification, and Reversal

进行中
Ke He, Synesis AI (ai4learningwhu.cn), Supervisor: Mang Ye

  • 聚焦 AI 辅助学习中生成参与弱化、流畅性幻觉与元认知失控等问题，分析其形成机制与行为表征。
  • 构建基于贝叶斯认知网络的四隐变量理论模型，设计五维行为观测体系与 PMI（伪理解风险指数），并基于 POMDP 探索认知保护干预方案。
