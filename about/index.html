# 👋 Introduction

Hi, I'm Ke He (Koen), an undergraduate student at Wuhan University (WHU).

I stand at the intersection of Computer Vision (CV) and System Engineering. My philosophy is simple: bridge the gap between cutting-edge algorithms and real-world applications. I strive not just to reproduce state-of-the-art methods, but to build systems that are Reproducible, Maintainable, and Deliverable.

  • 🔭 Research Interest: Cross-Modality Person Re-Identification (VI-ReID) & Multi-Agent Systems.
  • 🌱 Goal: To become a pioneer who drives change through AI.

# 🛠 Tech Stack

  • Core: Python · PyTorch · C++
  • Web: TypeScript · React · Node.js
  • Infra: Linux · Docker · HPC / Cluster Environment

# 🔬 Research & AI

1. Medical Diagnosis System (Knowledge Graph & RAG)

Full-stack medical auxiliary system combining structured knowledge and semantic reasoning.

  • Core: Combines Disease-Symptom Knowledge Graphs (KG) with Vector-based RAG for high-accuracy reasoning.
  • Stack: KnowledgeGraph, NLP, Vector DB.
  • Link: Live Demo

2. YaoZhiYunAn: Multi-Agent Disaster Prediction

Real-time situational awareness for emergency response.

  • Core: Built on a Multi-Agent System architecture for collaborative sensing, information fusion, and interpretable visualization.
  • Stack: Multi-Agent, Public Safety.

3. SamLora: Extreme Environment Housing Detection

Robust detection in complex terrains.

  • Core: Fine-tuned the Segment Anything Model (SAM) and integrated with ArcGIS Pro to adapt to challenging geographical data.
  • Stack: GIS, CV, Fine-Tuning.

4. CV Image Dehazing System

Engineering implementation for low-visibility restoration.

  • Core: A complete pipeline for restoring visibility in hazy images using advanced CV algorithms.
  • Status: Software Copyright (CSC No.2)

Complex scene understanding.
